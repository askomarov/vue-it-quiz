## Question

Which SQL statement is used to retrieve data from a database?

## Options

- FETCH
- SELECT
- GET
- RETRIEVE

## Answer

SELECT

## Explanation

The `SELECT` statement is the standard SQL command for querying data from one or more tables. It can filter, sort, and aggregate results using clauses like `WHERE`, `ORDER BY`, and `GROUP BY`.
