## Question

What does the HTTP status code 404 indicate?

## Options

- Server error
- Unauthorized access
- Resource not found
- Redirect required

## Answer

Resource not found

## Explanation

HTTP 404 means "Not Found" — the server cannot find the requested resource. It is a client error (4xx) indicating that the URL does not correspond to any existing resource.
