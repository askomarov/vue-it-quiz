## Question

Which HTML element is used to define the most important heading on a page?

## Options

- h1
- header
- title
- head

## Answer

h1

## Explanation

The `<h1>` element represents the highest level heading in HTML. There should typically be only one `<h1>` per page for proper document outline and SEO.
