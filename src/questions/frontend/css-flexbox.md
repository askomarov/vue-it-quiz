## Question

Which CSS property is used to align flex items along the main axis (horizontal)?

## Options

- align-items
- justify-content
- flex-direction
- align-content

## Answer

justify-content

## Explanation

The `justify-content` property aligns flex items along the main axis (horizontal by default). The `align-items` property aligns items along the cross axis (vertical by default).
