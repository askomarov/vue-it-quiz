## Question

Which method is used to add an event listener to a DOM element?

## Options

- addEvent()
- addEventListener()
- attachEvent()
- onEvent()

## Answer

addEventListener()

## Explanation

The `addEventListener()` method is the standard way to attach event handlers to DOM elements. It allows multiple handlers for the same event and supports event capturing and bubbling phases.
