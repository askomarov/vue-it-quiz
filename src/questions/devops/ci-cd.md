## Question

What is the main purpose of Continuous Integration (CI)?

## Options

- To automatically deploy code to production
- To frequently merge code changes and run automated tests
- To monitor production servers
- To manage database migrations

## Answer

To frequently merge code changes and run automated tests

## Explanation

Continuous Integration is the practice of frequently merging developer code changes into a shared branch, followed by automated builds and tests. This catches integration bugs early and keeps the codebase in a deployable state. Continuous Deployment (CD) is the automated delivery step that follows.
